# NSAuth2 门户视觉升级设计方案（v1）

> 目标：向 NodeSeek 社区风格靠拢——「网格、条纹、高信息密度、克制蓝」，
> 建立品牌识别度，消除当前"模板感"。本文档是实施蓝图，确认后按 §7 范围执行。

---

## 1. 现状问题诊断

| # | 问题 | 根因 | 影响 |
|---|------|------|------|
| 1 | 组件色与自定义色打架 | naive-ui 未配 `themeOverrides`，按钮/链接/标签是默认**绿** `#18a058`，自定义样式是**蓝** `#1f6feb` | 页面色彩混乱，无品牌主色 |
| 2 | 布局无层次 | hero/卡片/列表都是"白底 + 1px 边框"同一质感 | 没有视觉焦点与节奏 |
| 3 | 无品牌资产 | 无 Logo、无专属图形、无纹理 | 一眼看不出是什么产品 |
| 4 | 信息密度低 | 大留白 + 大字号 + 少量弱化文字 | 社区感弱，像后台模板 |
| 5 | 无细节动效 | 全部静态、无 hover 反馈 | 缺乏质感 |

---

## 2. 品牌方向

**关键词**：NodeSeek 社区感 · 网格秩序 · 条纹节奏 · 克制蓝 · 高信息密度

**风格定位**：向 V2EX/NodeSeek 类社区门户看齐——
浅灰画布 + 白色卡片 + 蓝主色 + 灰弱化文字 + 网格/条纹细节；
不做渐变堆砌、不做大圆角、不做阴影漂浮。

---

## 3. 设计系统

### 3.1 色板（统一收敛）

| 角色 | 值 | 用途 |
|------|-----|------|
| **主色 brand** | `#1F6FEB`（沿用项目蓝） | 按钮/链接/激活态/重点数字 |
| 主色 hover | `#1A5CD0` | 悬停 |
| 主色浅底 | `#EAF1FE` | 标签底/选中底/信息条 |
| 辅助青 | `#0E9F6E` | 成功/在线/已授权 |
| 警示橙 | `#D97706` | 待审核/警告 |
| 危险红 | `#DC2626` | 错误/撤销 |
| 画布背景 | `#F5F6F8` | 页面底 |
| 卡片/导航 | `#FFFFFF` | 卡片、导航、页脚 |
| 主文字 | `#1F2329` | 标题/正文 |
| 次级文字 | `#6B7280` | 说明/时间/元信息 |
| 边框 | `#E3E6EB` | 卡片/分割线 |
| 网格线 | `rgba(31, 41, 55, 0.05)` | 背景网格纹理 |

**落地**：`NConfigProvider :theme-overrides` 全量收敛 naive-ui 组件色
（primary/primaryHover/success/warning/error/文本/边框/圆角），
CSS 变量同步，一套色板两处引用，消灭绿蓝打架。

### 3.2 网格与条纹（「格子」的诠释）

1. **背景微网格**：全页画布铺 24px 网格纹理（CSS 线性渐变实现，1px 网格线，4% 透明度）——社区/技术感来源；
2. **Hero 强调网格**：hero 区网格线加深（8%），叠加一条品牌蓝细线底边（2px `#1F6FEB` 渐变到透明），形成"工程感横幅"；
3. **斑马纹列表**：表格/授权列表/应用列表隔行 `#FAFBFC` 底色（社区论坛经典条纹）；
4. **条纹点缀**：Logo 与标签使用 45° 斜纹或格点纹理，呼应"格子条纹"。

### 3.3 字体与排版

| 层级 | 字号/字重 | 用途 |
|------|-----------|------|
| H1 | 26px / 700 | hero 主标题 |
| H2 | 17px / 600 | 区块标题（带 3px 品牌蓝左条） |
| H3 | 15px / 600 | 卡片标题 |
| 正文 | 14px / 400 | 默认 |
| 弱化 | 12px / 400 `#6B7280` | 元信息/说明 |
| 数字 | `font-variant-numeric: tabular-nums` | 统计/ID/验证码 |

字体栈沿用系统栈（PingFang/微软雅黑/Segoe UI），不引外部字体。

### 3.4 形状与阴影

- 圆角：卡片 8px、按钮/输入框 6px、标签 4px（**收紧**，替代当前 14px 大圆角）
- 阴影：默认无；hover 时 `0 2px 8px rgba(31,41,55,.06)`（轻、克制）
- 边框：统一 1px `#E3E6EB`

### 3.5 品牌 Logo（CSS/SVG 内联实现，无图片资产）

**概念**：网格方块 + 钥匙孔（OAuth 授权语义）。
- 方块阵 3×3，左上角 2 格品牌蓝实心，其余描边——"格子"
- 右下角格内放钥匙孔圆+槽（SVG path）——"授权"
- 文字标：`NSAuth2` 用 `#1F2329`，`NS` 两字母品牌蓝
- 尺寸：导航 28px、hero 56px、favicon 16px（data URI 注入）

### 3.6 动效（轻量）

- hover：卡片上浮 1px + 阴影；按钮色变 150ms；链接下划线
- 进入：区块 200ms fade-up（`@media (prefers-reduced-motion: no-preference)` 才启用）
- 加载：骨架屏用 naive Skeleton；验证码等待用倒计时数字跳动（tabular-nums）

## 4. 门户首页（/）逐区块设计

### 4.1 导航（全局）
白底、底边 1px；左侧 Logo + `NSAuth2`；右侧文档/登录按钮；
**登录按钮 = 品牌蓝实心**，未登录时全站唯一主 CTA 位置。

### 4.2 Hero（首屏）
- 背景：加深网格纹理 + 底部品牌蓝渐变细线
- 内容：56px Logo → H1 `NSAuth2 · Nodeseek OAuth2 授权服务` → 副标题
- 副标题做成 **"标签化"**：三个小标签（`OAuth2 标准` `私信验证码` `多账号冗余`）替代纯文字
- CTA：主按钮（登录）+ 两个文字按钮（接入文档/申请接入），居中
- 右下角：一行小字统计 `已接入 N 应用 · 今日授权 M 次`（数字 tabular-nums）

### 4.3 三方角色（卡片网格）
- H2 带品牌蓝左条
- 3 列网格（窄屏 1 列），卡片：**左上角 36px 圆角方块图标**（🔐🧩👤 改绘成几何徽标底）+ 标题 + 弱化描述
- 卡片 hover：上浮 + 边框变品牌蓝浅色

### 4.4 三步私信验证
- 横向三步（箭头连接），**步骤号改为品牌蓝圆形徽标**（①②③ → 蓝底白字圆点）
- 每步下方加细条纹分隔线，呼应"条纹"

### 4.5 特性 + 页脚
- 特性：标签云（品牌蓝浅底圆角标签）
- 页脚：**上边框 1px + 网格纹理底**，居中文字，品牌蓝小字链接（GitHub/文档）

## 5. 全站统一（不只首页）

- `themeOverrides` 收敛：NButton/NTag/NCard/NInput/NAlert/NEmpty/NTable 等主色、圆角、边框
- 所有视图的 H2 统一"品牌蓝左条"样式（现 `.page-title` 升级）
- 卡片圆角 8px、边框统一
- 斑马纹应用到：Admin 审核队列、Grants 授权列表、Dashboard 应用统计
- 登录向导页（LoginView）：卡片居中 + 验证码数字用等宽 tabular-nums 加大显示
