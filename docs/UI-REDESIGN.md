# NSAuth2 门户视觉升级设计方案（v2，按 NodeSeek 实测风格修订）

> 目标：**复刻 NodeSeek 社区风格**——GitHub 绿主色 + 灰色文字体系 + 极简 Pure 风 + 高信息密度。
> 已实测抓取 nodeseek.com 的 CSS 变量体系（--main-color #2ea44f 等），本方案以其为基准。
> 本文档是实施蓝图，确认后按 §7 范围执行。

---

## 0. NodeSeek 风格实测结论（第一手 CSS 数据）

| 元素 | NS 实测值 | 说明 |
|------|-----------|------|
| 主色 | `#2ea44f`（--main-color） | GitHub success 绿 |
| 辅助绿 | `#45ca6b` / `#44aa77` | 渐变/点缀 |
| 主文字 | `#333` | 深灰非纯黑 |

| 背景 | `#fff` + `#fbfbfb` | 白 + 极浅灰分区 |
| 边框 | `#e5e7eb` / `#d9d9d9` | Tailwind 灰 |
| 语义色 | GitHub Primer 全套 | 蓝 #1f6feb / 红 #cf222e / 绿 #1a7f37 / 黄 #9a6700 / 紫 #8250df |
| 框架 | Pure CSS + theme-switcher | 极简、直角、无阴影、高密度 |

## 1. 现状问题诊断

| # | 问题 | 根因 | 影响 |
|---|------|------|------|
| 1 | 组件色与自定义色打架 | naive-ui 未配 `themeOverrides`，按钮/链接/标签是默认**绿** `#18a058`，自定义样式是**蓝** `#1f6feb` | 页面色彩混乱，无品牌主色 |
| 2 | 布局无层次 | hero/卡片/列表都是"白底 + 1px 边框"同一质感 | 没有视觉焦点与节奏 |
| 3 | 无品牌资产 | 无 Logo、无专属图形、无纹理 | 一眼看不出是什么产品 |
| 4 | 信息密度低 | 大留白 + 大字号 + 少量弱化文字 | 社区感弱，像后台模板 |
| 5 | 无细节动效 | 全部静态、无 hover 反馈 | 缺乏质感 |

## 2. 品牌方向（v2 按 NS 实测修订）

**关键词**：NS 绿 · 灰字体系 · 极简 Pure 风 · 高信息密度 · 列表条纹

**风格定位**：忠实 NS 系——GitHub 绿 + 灰色文字 + 白/浅灰画布 + 紧凑列表；
网格纹理只做**轻量点缀**（NS 本体无网格背景，用户要求的"格子条纹"以列表条纹/分区线为主，网格为品牌点缀）。

## 3. 设计系统（v2 色板全面对齐 NS）

### 3.1 色板（NS 实测值直接采用）

| 角色 | 值 | 用途 |
|------|-----|------|
| **主色 brand** | `#2ea44f`（NS --main-color） | 按钮/链接重点/激活态/Logo |
| 主色 hover | `#1a7f37`（NS Primer 绿深） | 悬停 |
| 主色浅底 | `#e6f4ea` | 标签底/选中底/信息条 |
| 辅助绿 | `#45ca6b` | 渐变/成功点缀 |
| 主文字 | `#333`（NS --dark-color） | 标题/正文 |
| 次级文字 | `#555`（NS --fade-color） | 说明/时间 |
| 弱化文字 | `#888` / `#6b7280`（NS --gray-color） | 元信息 |
| 链接 | `#555` hover `#333`（NS 同） | 正文链接 |
| 成功 | `#1a7f37` | 已授权/成功 |
| 警告 | `#9a6700` | 待审核 |
| 危险 | `#cf222e` | 错误/撤销 |
| 信息蓝 | `#1f6feb` | 信息提示 |
| 画布背景 | `#fbfbfb`（NS --bg-sub-color）+ 白卡片 | 分区底色 |
| 卡片/导航 | `#ffffff` | 卡片、导航、页脚 |
| 边框 | `#e5e7eb` / `#d9d9d9` | 卡片/分割线 |
| 网格线 | `rgba(51, 51, 51, 0.045)` | 背景网格纹理（点缀） |

**落地**：`NConfigProvider :theme-overrides` 全量收敛 naive-ui 组件色
（primary=#2ea44f / primaryHover=#1a7f37 / success / warning / error / 文本 #333 / 边框），
CSS 变量同步，一套色板两处引用，消灭绿蓝打架。

### 3.2 格子与条纹（用户诉求落地）

1. **列表斑马纹（主）**：表格/授权列表/应用列表隔行 `#fbfbfb`——NS 列表节奏感；
2. **分区线条（主）**：区块间 1px `#e5e7eb` 分割线，替代大留白；
3. **Hero 网格（辅）**：hero 区 24px 微网格纹理（4.5% 透明度）+ 品牌绿 2px 底边线——"工程感"呼应格子；
4. **Logo 格点（辅）**：Logo 用 3×3 格点阵 + 钥匙孔，格点元素贯穿品牌。

### 3.3 字体与排版

| 层级 | 字号/字重 | 用途 |
|------|-----------|------|
| H1 | 26px / 700 | hero 主标题 |
| H2 | 16px / 600 | 区块标题（带 3px 品牌绿左条） |
| H3 | 14px / 600 | 卡片标题 |
| 正文 | 14px / 400 `#333` | 默认 |
| 弱化 | 12px / 400 `#888` | 元信息/说明 |
| 链接 | 14px / 400 `#555` hover `#333` | 正文链接（NS 同款灰链） |
| 数字 | `font-variant-numeric: tabular-nums` | 统计/ID/验证码 |

字体栈沿用系统栈，不引外部字体。

### 3.4 形状与阴影（Pure 风：直角、无影）

- 圆角：卡片 6px、按钮 4px、标签 4px（**NS/Pure 风格收紧**）
- 阴影：**默认无**；hover 轻 `0 1px 3px rgba(51,51,51,.08)`（克制）
- 边框：统一 1px `#e5e7eb`

### 3.5 品牌 Logo（CSS/SVG 内联实现，无图片资产）

**概念**：3×3 格点阵 + 钥匙孔（OAuth 授权语义），格点用品牌绿。
- 3×3 方块阵，左上角 2 格品牌绿实心，其余 `#e5e7eb` 描边——"格子"
- 右下角格内钥匙孔（圆+槽，SVG path）——"授权"
- 文字标：`NSAuth2`，`NS` 两字母品牌绿，`Auth2` 深灰
- 尺寸：导航 28px、hero 56px、favicon 16px（data URI 注入）

### 3.6 动效（轻量，同 v1）

- hover：卡片上浮 1px + 轻阴影；按钮色变 150ms；链接变 `#333`
- 进入：区块 200ms fade-up（尊重 prefers-reduced-motion）
- 加载：naive Skeleton；验证码等宽数字跳动

## 4. 门户首页（/）逐区块设计

### 4.1 导航（全局）
白底、底边 1px `#e5e7eb`；左侧 Logo + `NSAuth2`；右侧文档/登录按钮；
登录按钮 = 品牌绿实心（全站唯一主 CTA 位置）。

### 4.2 Hero（首屏）
- 背景：`#fbfbfb` + 24px 微网格纹理 + 底部品牌绿渐变细线
- 内容：56px Logo → H1 `NSAuth2 · Nodeseek 非官方 OAuth2 授权服务` → 副标题
- 副标题标签化：`OAuth2 标准` `私信验证码` `多账号冗余`（品牌绿浅底标签）
- CTA：主按钮（登录，品牌绿）+ 两个灰链按钮（接入文档/申请接入）
- 右下角统计小字：`已接入 N 应用 · 今日授权 M 次`（tabular-nums）

### 4.3 三方角色（卡片网格）
- H2 带品牌绿左条
- 3 列网格（窄屏 1 列），卡片：36px 圆角方块图标底（🔐🧩👤 几何化）+ 标题 + `#555` 描述
- 卡片 hover：上浮 1px + 边框变绿浅色 `#b4cdb9`（NS 浅绿）

### 4.4 三步私信验证
- 横向三步，步骤号 = 品牌绿圆形徽标（①→蓝底改绿底白字圆点）
- 步骤间用 `#e5e7eb` 分割线连接，呼应"条纹"

### 4.5 特性 + 页脚
- 特性：品牌绿浅底圆角标签云
- 页脚：上边框 1px + `#fbfbfb` 底 + 网格纹理，居中灰字，品牌绿小字链接

## 5. 全站统一（不只首页）

- `themeOverrides` 收敛：NButton/NTag/NCard/NInput/NAlert/NEmpty/NTable 主色=NS 绿、文本 #333、边框 #e5e7eb、圆角收紧
- 所有视图 H2 统一"品牌绿左条"（`.page-title` 升级）
- 卡片圆角 6px、边框统一、阴影默认无
- 斑马纹应用到：Admin 审核队列、Grants 授权列表、Dashboard 应用统计
- 登录向导：卡片居中 + 验证码 tabular-nums 加大显示
